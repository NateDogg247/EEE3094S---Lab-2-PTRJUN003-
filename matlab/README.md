# MATLAB code

Set Current Folder to this directory and run `run_all`, or `root_locus_design` for the root-locus method alone.

Implementations are divided into `config`, `identification`, `design`, `validation` and `simulink`. Parameters are read from the project root's `config/lab_parameters.json`.

Control System Toolbox is required. Simulink is required only for the model builder. Outputs go to `results/matlab`. See [the code guide](../CODE_GUIDE.md).
